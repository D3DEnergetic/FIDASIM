# Regression-test learning guides

These guides explain concepts shared by several regression workflows. They
provide the background needed to understand the architecture and data
boundaries without interrupting the main regression-test portal.

Read them in this order:

1. [Regression-test architecture](regression_test_architecture.md): how
   user-facing configuration becomes a compiled calculation and then
   regression-test products.
2. [HDF5 array ordering](hdf5_array_ordering.md): how multidimensional arrays
   cross the Fortran, HDF5, and Python boundary safely.
3. [Build system](build_system.md): how the environment scripts and Makefile
   hierarchy configure and build FIDASIM and its regression executables.

Test-specific physics, configuration schemas, reference-data ownership, and
pass criteria remain in each test's own portal.
