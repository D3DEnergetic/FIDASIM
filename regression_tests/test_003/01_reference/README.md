# Validate shared reference distributions

Test 003 does not own a separate copy of its reference distributions. It uses
the smooth energy-pitch distributions generated by Test 002 Stage 2 from the
committed Test 002 Stage 1 fixtures.

This stage validates that the indexed Test 002 files exist and satisfy the
distribution contract required by the Test 003 sampler. It does not transform,
copy, plot, or write reference data.

## Prerequisite

Generate the shared distributions first:

```bash
cd regression_tests/test_002/02_run_test
./run.sh input_config_A.nml
```

Then validate them:

```bash
cd regression_tests/test_003/01_reference
./run.sh input_config_A.nml
```

## Configuration schema

```fortran
&reference
  comment = 'Dataset A: shared Test 002 energy-pitch distributions'
  input_distribution_config = '../../test_002/02_run_test/input_config_A.nml'
/
```

| Variable | Type | Required | Description |
| --- | --- | --- | --- |
| `comment` | String | No | Human-readable collection description. |
| `input_distribution_config` | String | Yes | Test 002 Stage 2 configuration whose indexed outputs provide the references. |

Relative paths are resolved from this configuration file.

## Validation

The validator requires:

- contiguous three-digit indexed Test 002 output filenames beginning at `001`;
- one selected `r` and `z` location per file;
- valid one-dimensional energy and pitch grids;
- `f` with singleton spatial dimensions;
- finite, nonnegative distribution values and positive `denf`;
- scalar `species`, `atomic_number`, `mass_number`, `charge_state`, and `A`;
- identical species parameters throughout the collection.

The Test 002 files remain generated artifacts. The committed source of truth is
the Test 002 Stage 1 reference collection.
