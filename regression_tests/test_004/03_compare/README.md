# Compare deterministic and Monte Carlo ion sinks

This stage will compare the matched two-dimensional sink distributions,
energy and pitch marginals, and total reaction rates. Its configuration and
metrics will be defined after the deterministic and Monte Carlo
implementations establish their output contracts. The comparison configuration
and its plot controls will live in this directory rather than in the shared
calculation configuration.
